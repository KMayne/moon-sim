# Atmosphere assets

Copied verbatim from the npm package `@takram/three-atmosphere@0.19.1` (`assets/`), so they are
served from this site rather than fetched from a third-party host at runtime.

| File                          | Contents                                                        |
| ----------------------------- | --------------------------------------------------------------- |
| `transmittance.exr`           | Precomputed atmospheric transmittance (half-float EXR)          |
| `scattering.exr`              | Precomputed combined Rayleigh + Mie scattering (3D, half-float) |
| `irradiance.exr`              | Precomputed ground irradiance                                   |
| `higher_order_scattering.exr` | Precomputed multiple-scattering term                            |
| `stars.bin`                   | J2000 directions, magnitudes and colours of 9,096 stars         |

`single_mie_scattering.exr` is not needed: the loader runs in combined-scattering mode.
